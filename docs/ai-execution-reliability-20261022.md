# AI 执行可靠性：候选交付与恢复契约

日期：2026-10-22，Asia/Shanghai。此轮实现针对 GYing 模型队列与 local-ai-agent 出站桥接；生产替换被安全门禁阻断。代码、隔离测试与候选产物不等于线上已启用。

## 状态与回执

网站队列支持可选 AES-256-GCM 加密快照、独占写锁和同目录原子替换。所有任务变更落盘成功后才返回；写入失败恢复到上次已提交快照。问题/历史只随未完成任务保留，终态立即移除；回答及幂等哈希在完成后最多 15 分钟保留，维护器每 10 秒处理一次。停机期间不执行清理，启动恢复时先处理过期。备份可能继续保留密文，应按独立备份保留策略处理；不能宣称物理擦除。

每任务包含 owner、created、status、attempt、lease、leaseUntil、request/result 及请求/回执哈希。状态仍为 PENDING/RUNNING/SUCCEEDED/FAILED，取消返回 FAILED 与取消消息，兼容现有网页。队列最多 200 个保留任务、8 个未完成任务，模型端仍单并发。只读工具范围没有扩大。

- `POST /api/ai/query` 可附 `requestKey`（8–64 个 ASCII 字母数字、下划线或连字符）。同用户/同键/同请求返回同一模型任务，终态在保留窗口内亦可重取；同键换问题返回 409。确定性片库即时回答不进入模型队列。未给键时保留原每用户一个未完成任务行为。
- `DELETE /api/ai/jobs/{id}` 必须为任务本人；跨用户 404。取消拒绝之后的完成回执。取消使当前租约失效，当前只读模型请求可能继续至自身预算结束，不能宣称立即中断推理。
- 桥接领取显式提交 `{leaseProtocol:1}` 时租约 45 秒；每 5 秒独立维护线程续期。旧客户端不声明协议时保持 210 秒租约且到期失败，兼容分步部署。
- `POST /api/internal/ai/jobs/{id}/renew` 使用专用桥接头及 `{lease}`。租约不能延长创建后的 240 秒任务总时限；可续期租约失效后最多再领取一次，旧租约回执 409。恢复后的重新领取属于新的 attempt，可能重新推理，只适用于现有只读工具。
- 同任务/同 lease/同原始结果哈希重复 complete 返回成功；改结果、取消后或旧 lease 返回 409。任务已过保留窗口则返回 409。

本机桥接在推理前落盘领取检查点，推理后先落盘完整回执再发送；重启发现完整回执仅重传，不重新领取/推理。中断时只剩领取检查点则发送 BRIDGE_INTERRUPTED 失败回执，不重放该 attempt。回执保存至创建检查点后 15 分钟、按原目标 origin 绑定，成功或 409 后清除。配置/密文损坏、被占用或写入失败均拒绝继续执行，不打印问题、工具正文或密钥。

## 启用与回退

持久化默认关闭，必须提供状态路径与单独私有密钥文件，缺一个会拒绝启动；没有自动生成、复制或旋转生产密钥。密钥内容至少 32 字节，使用带固定域分隔的 SHA-256 派生 AES key。密钥应采用随机材料与受限文件权限。状态专用目录与文件在 POSIX 为 0700/0600，在 Windows 设置 owner-only ACL；拒绝符号链接/联接/其他重解析路径。锁仅保证同文件单写者，本实现适用单后端实例、同机持久卷，不能宣称分布式数据库事务或多副本安全。

| 系统 | 必须配置 |
| --- | --- |
| GYing backend | `APP_AI_STATE_FILE` 指向专用持久目录中的队列文件；`APP_AI_STATE_KEY_FILE` 指向单独只读私有密钥挂载 |
| 本机 Agent | `LOCAL_AI_GYING_STATE_FILE`、`LOCAL_AI_GYING_STATE_KEY_FILE`；启动脚本发现 `.local/gying-state-key.bin` 时把状态指向 `.local/ai-state/bridge.bin` |

GYing Compose 仅新增默认空的环境变量契约，没有挂入生产密钥或启用状态。建议队列目录为 backend-data 下独立 `ai-state` 子目录，权限设置会作用于状态文件的直接父目录，不能把已有共享 data/logs 目录直接设为状态父目录。本机 `.local` 和生产密钥/状态不进 Git。

上线前先解决/批准门禁、保存两个原运行包/镜像和实际覆盖、加密备份状态与密钥恢复材料、确认无在途 AI 任务；仅协调 backend 与本机 bridge。先上兼容 GYing backend，再上本机 Agent。旧后端和新桥接的 renew 路径可能 404，新桥接仍可在旧 210 秒租约内回传；不以此当作已具备续期。回退同样先排空桥接再替换版本，保留密文文件、密钥和卷；旧版本会使用内存队列，无法恢复候选新增任务，不删除快照或用数据库 dump 覆盖线上数据。
