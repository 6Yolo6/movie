# AI 找片、猜你喜欢与上线验收

实现与上线：2026-10-20；续验：2026-10-21，Asia/Shanghai。

“我想看蜘蛛侠”原先进入小模型的有限搜索工具，只返回最多三项。现在明确片名查询由服务端完整检索标题、英文名、别名和系列名，返回总数及分页；详情和资源追问仍通过本机模型与真实工具证据回答。登录用户可使用“猜你喜欢”，每部影片附推荐理由；页面保留“内测中”，回答不再携带模型名称。

## 检索与推荐

- `CatalogAiService` 负责意图分流与 SQL 检索。默认每页 20 项，支持 1–30 项；按完整片名优先、年份、季与 ID 稳定排序，转义 LIKE 通配符。只返回 ACTIVE 且未软删除的影片。实库“蜘蛛侠”中文关键词命中 20 项，分三页、每页七项无重复；英文标题相关条目不等于中文关键词的全部命中。
- 推荐画像使用最近 100 条收藏（权重 3）及 90 天内、按影片去重的登录浏览（权重按 30 天衰减），排除已收藏/浏览的影片。浏览只由登录详情页提交，相同影片 30 分钟内按 SQL 去重；不从 IP 或访客哈希推断身份。并发请求去重没有唯一约束，不承诺严格 exactly-once。
- 内容相似度综合类型、导演、演员和分类；类型偏好采用逆频率加权。item co-favorite 信号要求至少两位独立共同收藏者，稀疏数据时以内容为主。个人排序权重为内容 55%、共同收藏 20%、评分 15%、热度 10%；无有效画像时评分/热度为 75%/25%。前 300 候选使用多样性重排，降低同系列集中展示。
- 年份、类型、分类与“高分”（至少 8）条件共同生效。推荐理由由参与排序的实际信号生成，不由模型编造。目录缓存 60 秒，最多读取 50,000 部；共同收藏输入最多 50,000 行。这些是当前规模上限，不是大规模检索性能承诺。j
- 本机 Vue 查询页只保留本地工作区与系统查询，移除片库选择器及片库示例；GYING 工具继续供项目网页/OpenClaw 内部桥接使用。
