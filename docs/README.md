- 当前事实集中在状态手册；参数和操作流程集中在专项手册，历次验收从历史索引进入。

- 历史镜像、授权、盘符和任务状态不能直接复用。仓库外材料须执行前确认存在和适用性。
- 只记录凭据键名、路径和状态，不写真实配置、完整 inspect 或原始日志。
