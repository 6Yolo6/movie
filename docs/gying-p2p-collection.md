## 来源契约

紧凑 downlist.list 使用并行数组：k=0 为 BT（目录/压缩包跳过），t 标题≤255，u 稳定 BT ID/source_ref，hex 为仅 source 内存使用的下载票据。/dbt/{u} 与带票据 URL 不是普通用户公开下载；外发移除并在磁力附 archive_torrent=true/字幕证据。无票据只保存磁力，数组长度/身份错误明确失败，不把不透明编码当 BTIH。

磁力使用小写 BTIH，不附标题以免改名重复。每片1080P/4K各一版、至少一版中文字幕；国语/配音不算，未知不编造。完整字段/初始样本见旧原文。

## 选择与幂等

按影片+URL/hash 或分辨率槽位原位更新，公开种子镜像可按 BT ID 更新；账号下载地址不新增/公开刷新。所选公开资源全保存后才排 P2P_ARCHIVE，v2 torrentMagnetIds 指磁力，任务无账号下载URL/票据；影片/provider/版本指纹去重，新旧指纹兼容。历史行/任务保留，旧槽位变化先取消过期任务。详情/每日推荐/网页资源搜索过滤旧 /dbt/，磁力与自有归档仍可见，不恢复软删除或批删历史。

## 失败语义

严格 GET /resources/{typeCode}/{mid} 的非200/非JSON/上游拒绝/缺结构/BT展开失败报错，明确空数组合法。directResourceLinks 计完整影片的保存/更新次数，非新增行数；directResourceFailures 为失败影片数。失败保留元数据但主位置不推进，原批次幂等重试。网盘独立审计、30分钟/最多3次，全部文件和自有分享确认后入库，HTTP200/排队不算成功。
