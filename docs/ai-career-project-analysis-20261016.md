目标是“Java 后端 + AI 应用开发”，用真实业务闭环、受控工具、可引用检索与同数据评测形成可展示成果；不把调用模型写成训练经验。

| 阶段 | 计划与当前进度 |
| --- | --- |
| 0 真实边界 | 核对 local-ai-agent/GYing 的README、配置、MCP、运行端点；本轮没有重做另一仓库全部审计 |
| 1 Agent闭环 | 前序已实现网页/QQ受控桥接和真实工具证据；本轮已贯通安全trace和联网工具边界/失败回归；完整会话独立评测仍待补 |
| 2 GYing真实场景 | “找近几年偏烧脑、时长不超过两小时的科幻电影”已落地条件解析+简介词法检索/分页；embedding混合、独立多轮评测和文档RAG导入/删除/引用未完成 |
| 3 评测/API | 已有40合成题、旧基线、隔离SQL/页面与部署证据；100–150独立人工留出题、真实错例、API Key哈希/撤销/配额/审计/token预算待补 |
| 4 求职交付 | 已有可复现报告与可用措辞；原简历更新、3–5分钟演示、检索/可靠性复盘、企业合成评分解释未完成 |

优先解决冷索引/误召回，补独立题集和调用轨迹，再同数据比较BM25、embedding、混合召回。企业评分只使用合成数据，不引入公司人员资料/源码。本轮特征与词法检索未新增训练、向量或文档RAG；性能收益仅固定合成计算场景，不能写线上准确率/CTR。
