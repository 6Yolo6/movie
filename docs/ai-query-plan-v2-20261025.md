## 实现边界

- 仅明确已知片名和简单泛推荐直返；复杂中文进入结构化查询计划，不生成 SQL、URL、用户身份或执行动作。1–2字符短片名只匹配完整名或分隔别名，避免 IT 命中 Titanic、她命中她们；已唯一定位的片库剧情不被联网确认覆盖。
- 片库确定性执行分类、人物/排除、范围、评分来源和排序；地区/语言各自使用JDK Locale中英文名与ISO编码归一，保留中国大陆、香港、台湾和普通话/粤语业务别名，避免英文地区名漏检或国家/语言编码混用；从原文补回真实人物字典中的遗漏，完整姓名优先于其中的短姓氏；原文能确定完整姓名时收窄模型的局部人名，唯一别名/小错可消歧，无法确认时说明。剧情召回去除通用请求词，避免电影、人等字眼独立召回无关资料。
- 序号与上一轮结果由服务端当前用户、有效任务、候选顺序和租约决定。翻页保存新的候选上下文，失败轮不进入后续历史。
- BM25 与 BGE-M3 候选融合，活库 ID 和内容 fingerprint 过滤过期向量；模型按核心主题允许细节近似，用实际简介片段核对相关性，候选数和“可能符合”分别说明。
- 搜索访问固定 Bing 搜索页面，解析有界 HTML、域白名单与实际搜索结果，保留来源/查询时间、原始/身份/相关性筛选数量；已定位影片的类型/年份排除同名异版。实际条目名与年份精确匹配时可仅保留影片身份链接，明确搜索摘要未验证剧情；不访问模型生成 URL，不把搜到链接称为当次逐页验证。
- 模型输出长度/上下文有界，失败保留错误码和调用轨迹。候选和搜索资料作为数据，不作为系统指令。
