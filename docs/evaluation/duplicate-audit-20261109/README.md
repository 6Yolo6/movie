## 现有扫描器为什么漏检

18:06 的生产只读 SQL 复现中，现有扫描器最新 100 / 200 条均命中 0 组。MobLand 的 TMDB 记录在 8,702 条 TMDB 记录中按创建时间倒序排第 7,989，超出这两个窗口；即使指定它，现有四个标题/剧集名/别名条件也均不匹配。

[页面按钮](../../../frontend/src/app/admin/resource-hub/page.tsx)固定传 `limit=100`。[后台入口](../../../backend/src/main/java/com/gying/movie/controller/ResourceHubAdminController.java)仅取最近 100 条 `tmdb_` 记录，最多 200 条，不是全库扫描；`findCanonicalMovie` 只优先选一个标题做精确匹配或 aliases 子串匹配，不归一化空格和 Season/第几季后缀，故 `MobLand` 不等于 ` MobLand Season 1`。

未来修复还须保留类别/年份/季数和版本冲突守护；现有合并逻辑未覆盖来源身份、百度及迅雷等新增关联，不能直接扩大扫描后批量合并。本轮另发现 194 条影片的 metadata TMDB ID 与来源身份不一致（221 条身份差异），这是独立的数据身份问题，不计入重复数量。
