## 分数与未知边界

0为关键错误或无可用答案，1为部分支持，2仅表示在本次声明证据范围内满足该维度，null保留实际事实未知。没有把引用真实片库文本直接当作语义蕴含通过：旧胶片修复与电影院核心场景两例仍失败。简介没有提及场景不能证明影片没有该场景；这三条事实维度为null，但是否交付所求依据仍可分别判断。

RAYE条目虽被片库分为电影，简介却写电视特辑，身份冲突单独待验。《燃烧》给出同片《烧仓房》真实引文，但正文仍标原作关系待核验；原始对白和动物伤害排除也没有额外事实证据。公告空结果不证明官方没有宣布；正文承诺有摘要与链接却无保留结果，已单独记录。

早期列表导演查询准确指向第一轮1MeM，年份替换/类型保留/偏好撤回也有计划机制证据。这些观察不能消除模型对主题的误判，也不能替代Movie任务链的owner/TTL、幂等与恢复测试。
